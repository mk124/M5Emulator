# GNU Unifont 15.1.05

The unmodified bitmap font and its SIL Open Font License 1.1 were copied from
SDL 3.4.16 `test/unifont-15.1.05.hex` and `test/unifont-15.1.05-license.txt`.
Copyright belongs to the GNU Unifont contributors.

- Upstream: https://unifoundry.com/unifont/index.html
- Distributed source: https://github.com/libsdl-org/SDL/tree/release-3.4.16/test
- License: [SIL OFL 1.1](unifont-15.1.05-license.txt)

The emulator renders this font directly as pixels for filenames and paths.
It covers Unicode's Basic Multilingual Plane; unsupported code points use the
replacement glyph. The emulator does not perform complex-script shaping.
